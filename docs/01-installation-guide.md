# Installation Guide

Below you will find a step by step guide for the installation of the Magento Coupon Import extension. The extension is free and open source, released under the MIT License. Its source code and releases are published on GitHub in the [magento1-coupon-import](https://github.com/PluginCompany/magento1-coupon-import) repository.

Please follow the installation guide carefully to prevent errors in your production environment.

> **Note:** Always install the extension on a staging server first in order to detect any issues which might arise and make a backup of your production environment before migrating.
